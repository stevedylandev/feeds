Now that you've seen RSS in action, there's a few things you can do:

  • Share this feed with someone else so they can also learn about RSS.
  • You're the "someone else" that got sent here and not sure what this is? Check out the root of this website here.
  • Keep using this free app by bookmarking the URLs for specific feed collections.
  • Download a dedicated RSS reader. These will have many more features and let you sync across devices. A few include NetNewsWire, Current, or FeedFlow.
  • Create your own RSS feed that you can share with others. A quick and no nonsense way to do this is to use an app like sourcefeed. The old fashioned way is to start a blog with something like Pagecord or BearBlog.

The web doesn't have to be a walled garden; we can make it open again.
